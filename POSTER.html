1. Problem Statement & Motivation

Real-time chat on Discord hosts millions of asynchronous, high-velocity discussions. Analyzing this data is challenging:

  • Lexical Noise: Highly saturated with gamer slang ("clutch", "diff", "inting"), shorthand, and emojis.
  • Entity Ambiguity: Standard NER models misidentify gaming titles and publisher organizations.
  • Black-Box Opacity: Lack of glass-box interpretability and honest test set validation.
Project Goal: Build a complete, production-grade interactive platform converting raw Discord conversations into actionable community intelligence, graph networks, and game recommendations.

10. MLOps Drift Monitoring (PSI Metric)

Monitors longitudinal Covariate & Concept Drift across Baseline (first 50%) vs Recent (last 50%) periods:

PSI = Σ (Recent% - Base%) × ln(Recent% / Base%)

• PSI < 0.1: Stable distribution (No shift).

• 0.1 ≤ PSI < 0.25: Moderate covariate shift.

• PSI ≥ 0.25: Severe drift requiring model retraining.
